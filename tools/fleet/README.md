## Konwencje

- Identyfikator story: `NNN-slug` = gałąź = `specs/NNN-slug/` = `runs/NNN-slug/`. `.specify/feature.json` nie istnieje w repo (gitignore) — SpecKit rozpoznaje story po gałęzi; stray plik → usunąć.
- Każdy nowy agent floty = plik `.claude/agents/<agent>.md` **i** wpis w `fleet-acl.json` (z `runs/*/prompts` w `read_allow`) **i** `npm run acl:test` zielony; `prompt-builder` odmawia dla agenta bez wpisu.
- `generated/` i `runs/` są commitowane (provenance); `tools/fleet/node_modules` nie.
- Skrypty nie piszą do `decisions.jsonl` pola `decided_by` inaczej niż z `journal.jsonl` (`OWNER_ANSWER`).
- Testy skryptów: `npm run acl:test`, `npm run migration:test`; pozostałe skrypty testowane ręcznie na syntetycznych wejściach (zob. historia w `docs/agent-fleet-v4/`).
- Journal: `GATE_*` piszą tylko skrypty bramek — `decide.js --gate` (GATE_ANSWER) i `migration-check.js` (GATE_OPEN G2b); `journal.js` ich nie przyjmuje. Odpowiedź właściciela istnieje dla skryptów tylko jako `OWNER_ANSWER` z AskUserQuestion (hook projektowy), nigdy z czatu.
